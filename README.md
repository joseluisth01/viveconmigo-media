# viveconmigo-media

Vídeos verticales para Instagram y TikTok de [Vive Conmigo](https://vive-conmigo.es), generados con un motor HTML + Playwright + ffmpeg.

- `engine.html` + `render.js`: motor de vídeo a partir de un spec JSON (`specs/`).
- `videos/`: MP4 publicados (se sirven vía jsDelivr para Metricool).
- `PLAYBOOK.md`: reglas de marca, formatos y publicación.
- `LOG.md`: registro de lo publicado.
